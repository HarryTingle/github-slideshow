# Interviews

One file per conversation: `YYYY-MM-DD-practice-role.md`. Use `_template-interview.md`.

## How to run one

**Do not demo.** A demo turns an interview into a reaction. Ask about the last time they did the thing.

**The spine:**
1. Walk me through the last complex engagement model you built. What did you actually do, step by step?
2. How long did it take, and who else touched it?
3. What broke? What did that cost?
4. When the client asked for a different commercial shape, what happened next?
5. Who else needed a version of that model — resourcing, SLT, the client? What did you build for each?
6. What proportion of your bids now involve fixed price or contingent fees? Is that changing?
7. What would have to be true for you to stop using Excel for this?
8. Who decides whether a tool like this gets bought, and what happened last time you bought one?

**Listen for:** workarounds they have stopped noticing, the moment in the story where they sigh, and anything they built themselves.

**Record:** their words, not your summary. Timestamps if recorded. The contradiction as well as the confirmation.
